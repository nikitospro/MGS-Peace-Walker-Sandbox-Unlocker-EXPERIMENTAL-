## What to include in a report

- Game version shown by the current release/patch
- `PWSandboxUnlocker.log`
- Whether Weapons, Items, and Uniform menus work
- Whether the game crashes or displays repeated development notifications

Do **not** upload your game EXE or copyrighted game files to the project issue tracker.
